# Golf Simulator Setup Guide

Use this checklist each time you start the simulator. Follow the steps in order so the projector and GCHawk are ready before you launch GSPro.

## Quick-start checklist

- [ ] Turn on the projector with the **long white remote**.
- [ ] Turn on the **GCHawk** with the **white puck remote**.
- [ ] Wait until both devices have finished starting up.
- [ ] Turn on the computer.
- [ ] Turn on the mouse and keyboard.
- [ ] Launch **GSPro**.

For photos and additional instructions, see [How To](How%20To.md).

## If setup does not work

1. Confirm the projector and GCHawk are powered on.
2. Give both devices time to finish booting before continuing.
3. Confirm the mouse and keyboard are powered on.
4. Check the [How To](How%20To.md) guide and contact the simulator owner if you still need help.

Enjoy your game!
